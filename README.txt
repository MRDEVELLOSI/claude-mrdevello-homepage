이 폴더는 전체 사이트 HTML, CSS, JavaScript, 이미지, 폰트와 PDF를 포함합니다.
index.html은 메인 페이지입니다. mr-starter, mr-pro, mr-team, mr-check, mr-booster 등 하위 폴더에 각각의 HTML이 있습니다.

전체 사이트는 경로와 폰트 로딩을 위해 로컬 HTTP 서버로 열어 주세요.
1. 이 폴더에서 터미널을 엽니다.
2. python3 -m http.server 8000
3. 브라우저에서 http://localhost:8000 으로 접속합니다.

별도로 제공하는 MR-DEVELLO-main.html은 메인 이미지·폰트·스타일·스크립트를 포함한 단일 파일이며 파일을 직접 열 수 있습니다. 메인 메뉴의 하위 페이지·PDF·외부 링크는 실제 사이트 주소로 연결됩니다.
이 파일 묶음에는 서버 관리 권한, 계정 정보, 저장소 인증 정보가 포함되지 않습니다.
