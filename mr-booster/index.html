적용 전에 합의하는 검증 기준

어떤 업무부터 시작하면 좋을까요?

반복 빈도가 높고, 참고할 자료가 있으며, 결과를 사람이 확인할 수 있는 업무가 첫 후보입니다. 현재 업무 흐름과 기대 효과, 데이터 준비 상태를 함께 보고 우선순위를 정합니다.

기존 시스템을 전부 바꿔야 하나요?

현재 사용 중인 시스템과 도구를 먼저 살펴봅니다. API 제공 여부와 접근 권한을 확인한 뒤 연결 가능한 범위를 정합니다. 기존 환경의 제약에 따라 별도 개발이나 데이터 정리가 필요할 수 있습니다.

회사 자료를 외부 AI에 보내도 괜찮을까요?

자료를 연결하기 전에 외부 전송 가능 여부, 개인정보와 민감정보의 범위, 이용할 모델·서비스의 데이터 처리 조건을 확인합니다. 외부 전송이 어려운 경우에는 가능한 환경과 구현 방식을 먼저 검토하며, 지원 여부는 상담 후 확정합니다.

AI가 만든 답변은 자동으로 처리되나요?

처음에는 검색·분류·초안 작성처럼 담당자를 돕는 흐름부터 검토합니다. 고객 답변 발송, 중요한 정보 변경 등은 사람의 확인과 승인 지점을 정합니다. 자동 처리 범위는 오류의 영향과 검증 결과를 보고 합의합니다.

기간과 비용은 어떻게 정하나요?

검증할 업무 수, 데이터 준비 상태, 연결할 시스템, 화면과 보안 요구사항에 따라 달라집니다. PoC와 운영용 구축의 범위를 구분해 일정과 견적을 안내하고, 유료 모델·API·서버 이용료도 별도로 확인합니다.

기존 개발 서비스와는 무엇이 다른가요?

MR.BOOSTER는 기존 업무를 AI로 개선할 가능성을 진단하고 검증하는 프로젝트입니다. 새 서비스의 기획·프로토타입은 MR.STARTER, 앱·웹 전체 개발은 MR.PRO, 계속 이어지는 개발 협업은 MR.TEAM에서 필요한 범위를 함께 살펴볼 수 있습니다.
