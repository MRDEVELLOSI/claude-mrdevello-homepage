안정적인 서비스 유지

운영형

현재 기능을 안정적으로 유지하고, 운영 중 발생하는 문제를 맡길 팀이 필요한 기업을 지원합니다.

  • 정기 기능 점검과 시스템 상태 확인
  • 백업 확인과 복구 절차 관리
  • 보안 업데이트·접근 권한·인증서 점검
  • 장애 대응과 기존 기능의 오류 수정
  • 합의한 범위의 문구·이미지 변경

관리 대상·점검 주기·지원 시간과 수정 범위를 운영안으로 정리합니다. 신규 기능 개발은 별도 협의합니다.

운영형 상담

운영과 지속적인 기능 개선

운영·개선형

서비스를 운영하면서 사용자와 업무에 필요한 화면·기능을 꾸준히 개선하는 기업을 지원합니다.

  • 운영형의 모든 기본 지원
  • 개선 과제와 작업 우선순위 정리
  • 기존 화면과 사용자 흐름 개선
  • 합의한 범위의 신규 기능·연동 개발
  • 필요한 기획·디자인·개발과 검수

월 작업량·동시 진행 범위·일정을 먼저 합의합니다. 규모가 큰 신규 구축과 전면 개편은 별도 프로젝트로 협의합니다.

운영·개선형 상담

처음부터 필요한 유형을 선택합니다. 시스템 구조와 작업 규모를 확인한 후, 실제 제공 범위와 월 비용을 제안합니다.

운영·유지보수·보안 관리를 함께 진행합니다. 시스템에 필요한 점검과 처리 기준을 운영안에 명시합니다.

정기 점검과 운영 기록

주요 기능과 서버·시스템 상태를 정기적으로 확인합니다. 점검 결과, 수정 내역과 미결 과제를 기록하고 다음 조치에 연결합니다.

백업 확인과 복구 준비

백업 대상·주기·보관 기간·저장 위치를 정하고 백업 결과를 확인합니다. 데이터 복구 절차와 확인 범위를 함께 관리합니다.

보안 업데이트와 접근 관리

관리 대상 소프트웨어의 보안 업데이트, 관리자 권한과 HTTPS 인증서를 점검합니다. 서비스 영향을 검토한 후 합의한 범위에서 패치·설정을 보완합니다.

장애 대응과 기존 기능 수정

문제의 영향과 긴급도를 확인하고 합의한 우선순위로 대응합니다. 기존 오류를 수정하고 조치 결과와 후속 과제를 공유합니다.

운영·개선 업무의 예시

확인할 과제와 결과물을
같은 자료로 공유합니다.

개선 요청을 바로 개발하기 전에 필요한 변화와 작업량을 정리합니다. 참여 역할과 검수 기준을 연결하고, 진행 상황과 후속 작업을 공유합니다.

계약 전에 확인하는 기준

구체적으로 합의합니다.

지원 시간과 연락 체계
지원 요일·시간대·접수 채널·담당 역할을 정합니다. 야간·휴일 지원이 필요한 경우 제공 조건을 별도로 협의합니다.
장애 우선순위와 초기 대응
전체 서비스 중단, 주요 기능 장애, 일반 요청을 영향에 따라 구분합니다. 접수 확인·초기 대응 목표와 복구 목표를 구분해 안내합니다.
월 작업량과 동시 진행
운영·개선형의 월 작업량과 동시 진행 수, 검토 주기와 우선순위를 합의합니다. 범위를 넘는 요청은 일정·작업량·비용을 먼저 협의합니다.
월 비용과 외부 비용
관리 대상과 참여 역할에 따라 월 비용을 제안합니다. 서버·유료 API·라이선스 등 외부 비용과 별도 개발 비용의 부담 범위를 명시합니다.
범위 변경과 종료 인계
최소 이용 기간, 유형 변경, 미사용 작업량 처리와 종료 정산 조건을 확인합니다. 소스·문서·권한의 인계 범위를 계약에 명시합니다.

개발 완료 이후의 협업

운영 준비부터
지속적인 개선으로 연결합니다.

  1. 현황과 자료 확인

    시스템 구조, 소스·문서, 접근 권한과 운영 이력을 확인합니다.

  2. 유형과 운영안 합의

    운영형 또는 운영·개선형을 선택하고 지원 범위·시간·비용을 정리합니다.

  3. 운영 인수와 작업 진행

    필요한 자료와 권한을 인수하고, 합의한 기준으로 점검·수정·개발을 진행합니다.

  4. 결과 공유와 다음 과제

    조치와 검수 결과, 남은 과제를 공유하고 다음 작업의 우선순위를 정리합니다.

미스터디벨로에서 개발 중인 서비스는 개발 종료 전에 운영안을 제안합니다. 기존 시스템은 인수 검토 후 제공 가능한 범위를 안내합니다.

소스·문서·기술 구성과 접근 권한을 확인한 후 인수 가능한 범위를 안내합니다. 사전 정비가 필요한 경우 별도 작업과 조건을 제안합니다.

구독 유형의 선택과 변경

현재 필요한 지원에 따라 운영형 또는 운영·개선형을 선택합니다. 운영 중 필요한 업무가 달라지면 변경 시점·범위·비용을 협의합니다.

보안 관리의 범위

일상적인 보안 업데이트·접근 권한·인증서 등 합의한 항목을 관리합니다. 보안·비용·SEO·GEO 진단과 개선은 MR.CHECK로, 모의해킹·보안 인증 심사·전문 보안 관제는 별도 범위로 협의합니다.

추가 기능과 작업량 초과 요청

운영·개선형은 합의한 월 작업량 내에서 기능 개선을 진행합니다. 작업량을 초과하거나 별도 프로젝트 규모에 해당하면 작업 전 범위·일정·비용을 협의합니다.

비용과 최소 이용 기간

시스템 규모와 지원 수준, 참여 역할을 확인해 제안합니다. 월 비용·이용 기간·대응 시간·종료 조건을 계약 전에 명시합니다.
